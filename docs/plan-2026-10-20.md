# BACalc 實作計畫（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出仿 BA II Plus Professional 的離線財務計算 PWA（Python 引擎跑在 MicroPython），並產出 AI Agent 版、EMBA 版兩套教材（Prompt 卡＋PPT）

**Architecture:** Model 是 `engine/*.py`，只用 CPython 與 MicroPython 都支援的可攜子集，由 `engine/bridge.py` 用 JSON 字串進出。瀏覽器端由 Web Worker 載入 MicroPython 並呼叫 bridge；View 是原生 HTML／CSS／JS。golden 值由 Excel COM 產生並存成 JSON，CPython（pytest）與 MicroPython（Node）共用同一份。

**Tech Stack:** Python 3.11（pytest 7.4）、MicroPython 1.29.0 WebAssembly（npm `@micropython/micropython-webassembly-pyscript@1.29.0-6`）、原生 JS（ES module）、IndexedDB、Google Identity Services、Node 22（`node --test`）、Excel 16 COM（pywin32，只用來產生 golden）、pptxgenjs（create-info-ppt）、python-pptx

**Spec:** `docs/spec-2026-10-19.md`（2026-10-20 修訂版）

## Global Constraints

- MVC：Model＝`engine/`（無 I/O、不 import 瀏覽器相關模組）；Controller＝`engine/bridge.py`＋`web/js/app.js`＋`web/js/py-worker.js`；View＝`web/index.html`、`web/css/`、`web/js/views/`
- 可攜子集：`engine/` 禁止 import `decimal`、`datetime`、`ast`、`fractions`、`dataclasses`、`typing`、`functools`、任何第三方套件；可用 `math`、`json`
- 絕不產生看起來正常但錯誤的數字：算不出來回傳 `{"ok": false, "error": <中文原因>, "field": <欄位或 null>}`；結果含 `inf` 或 `nan` 一律視為錯誤
- 禁止 `eval`／`exec`
- 疊代求解：|f(x)| < 1e-10，最多 200 次；未收斂回錯誤
- 金額彙總用「分」整數，四捨五入為 half away from zero，只能呼叫 `engine/money.py`
- 日期用序數日（0001-01-01 為 1），格里曆，只能呼叫 `engine/dates.py`
- golden 值每筆都有 `source` 欄位（Excel 公式字串，或 TI Guidebook 頁碼）；對不上就回報，不改 golden 硬湊
- 雙執行環境：同一 golden 案例 CPython 與 MicroPython 差異 > 1e-9（相對誤差）即失敗
- 檔案、註解：Python PEP 8，註解繁體中文、重要名詞附英文
- 新增 web 檔案必須列進 `web/sw.js` 的 `APP_SHELL`；`CACHE_VERSION` 與 `web/js/app.js` 的 `APP_VERSION` 同步
- 每次驗證產生 `logs/verify-YYYYMMDD-HHMM.html`（含 commit hash），跑之前 git 必須乾淨
- 每個 Task 結束追加 `DEVLOG.md`（需求／做法／產出／驗證／問題與修正／待辦）
- 安裝套件、推送 GitHub、關閉使用者開著的程式（Excel、PowerPoint）前，先問使用者
- 教學步驟 tag：`step0`～`step9`，打在規格書 5.2 節指定的位置

## Review Focus

1. **I/Y＝0 或極小**：TVM 公式除以 i 會爆掉；應改用 i＝0 的極限公式（PV＋PMT·N＋FV＝0），結果與 i＝1e-12 連續 → Task 5 加 `test_tvm_zero_rate`
2. **溢位與非有限值**：N＝1e6、I/Y＝1000 時 `(1+i)**N` 變 `inf`，畫面不可顯示 `inf` 或亂數 → Task 1 `result.ok()` 檢查有限值，Task 5 加 `test_tvm_overflow_is_error`
3. **留空格數不對**：全部填滿、或留兩格以上空白時，要明確說明「請只留一格空白」，不可默默算某一格 → Task 16 加 `test_bridge_blank_count`
4. **歐式千分位輸入**：設定為 EU 時，`1.000,50` 要解析成 1000.5；US 模式下 `1,000.50` 也是 1000.5；兩種模式下 `1.000,50` 不能被誤讀成 1.0 → Task 15 加 `test_parse_number_locale`
5. **日期邊界**：2 月 29 日、月底與 30/360 規則（例如 1/31 → 2/28）要與 Excel `DAYS360` 一致 → Task 4 加 `test_days360_month_end`

### Task 5：TVM（打 tag step2）

**Files:**
- Create: `engine/tvm.py`
- Test: `tests/test_tvm.py`

**Interfaces:**
- Consumes: `result.ok/err`、`solver.find_root`
- Produces:
  - `period_rate(iy: float, py: float, cy: float) -> float`：`(1 + iy/100/cy) ** (cy/py) - 1`
  - `solve(inputs: dict, unknown: str) -> dict`：`inputs` 鍵為 `N, IY, PV, PMT, FV, PY, CY, BGN`（BGN 為 bool），`unknown` 是五個 TVM 變數之一；回傳 `ok({unknown: 值})`
  - `tvm_residual(n, i, pv, pmt, fv, bgn) -> float`（Task 6 也用）

TVM 方程式（i 為每期利率，k = 1 if BGN else 0）：
- i ≠ 0：`PV·(1+i)^N + PMT·(1+i·k)·((1+i)^N − 1)/i + FV = 0`
- |i| < 1e-12：`PV + PMT·N + FV = 0`
- 求 N：`N = ln((PMT·(1+ik) − FV·i) / (PMT·(1+ik) + PV·i)) / ln(1+i)`；真數 ≤ 0 時回 `err("此組數值無法求出 N：現金流方向需相反", "N")`
- 求 I/Y：`find_root` 求 i，範圍 (−0.9999, 10]，猜測值 0.01；再換回 `IY = CY·((1+i)^(PY/CY) − 1)·100`

### Task 14：計算機算式與記憶

**Files:** Create `engine/calc.py`、`engine/memory.py`；Test `tests/test_calc.py`、`tests/test_memory.py`

**Interfaces:**
- `evaluate(expr: str, mode: str = "AOS", ans: float = 0.0, mem: dict | None = None) -> dict`：`ok({"value": float})`
- 文法（遞迴下降）：

```
expr    := term (('+'|'-') term)*
term    := unary (('*'|'×'|'/'|'÷') unary)*
unary   := ('-'|'+') unary | power         # 負號優先序低於 ^：-2^2 = -4
power   := postfix ('^' unary)?            # 右結合：2^3^2 = 512
postfix := primary ('!' | '%' | '²')*
primary := NUMBER | 'ANS' | 'M'[0-9] | FUNC '(' args ')' | '(' expr ')' | '√' postfix
FUNC    := sqrt ln exp inv nPr nCr        # nPr(n,r)、nCr(n,r)
```

- 算式中的逗號只當函式參數分隔，**不接受千分位**（避免 `nCr(5,200)` 歧義）；UI 在送出前不轉換
- `%`：一般情況為 ÷100；作為 `+`／`-` 的右運算元時為「左邊 × b/100」（`200+10%` = 220），與計算機習慣相同
- Chain 模式：`+ − × ÷ ^` 一律由左到右，不分優先順序（`2+3×4` = 20）
- 錯誤：除以零、`ln` 非正數、`!` 非整數或 > 170、括號不平衡、未知符號 → `err("…", "expr")`，訊息指出位置
- `memory.py`：`Memory` 類別，`store(i, v)`、`recall(i)`、`add(i, v)`、`sub(i, v)`、`mul(i, v)`、`div(i, v)`、`accumulate(v) -> {"sum", "count"}`、`to_dict()`／`from_dict()`
