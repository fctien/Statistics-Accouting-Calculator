# BACalc 手動 e2e 檢查表（in-app 瀏覽器）

> 使用者尚未同意安裝 Playwright，因此 UI 層以此表手動檢查。自動驗證（引擎、golden、JS 單元、Worker）請跑 `python tools/verify_all.py`。
> 起手：`python tools/build_web.py`，啟動預覽伺服器（根目錄為 `web/`），開啟 `/index.html`。設定頁維持預設（小數位數 2、千分位開、日期 yyyy-mm-dd）。
> 每張工作表：填入下列輸入 → 按指定動作按鈕 → 對照「預期顯示」。出處是 `tests/golden/excel.json` 的 Excel 公式。

## B. 離線重新載入

1. 載入頁面一次（Service Worker 安裝完成，狀態列顯示可離線）
2. DevTools Network 勾選 Offline（或停止預覽伺服器）
3. 重新整理 → 頁面仍載入、TVM 第 1 項仍算出 -1,798.65
4. 預期：不出現白畫面；恢復網路後正常

## C. Service Worker 更新（SHELL_HASH 變更）

1. 記下 `web/sw.js` 的 `SHELL_HASH`（或頁面上的版本）
2. 改任一殼檔案（例如 `web/css` 內加一個空白註解）→ `python tools/build_web.py` → SHELL_HASH 應改變
3. 重新整理 → 出現「有新版本」提示，套用後載入新內容、舊快取被清除
4. 還原該改動並重建；`python tools/check_shell.py` 通過

## D. 情境儲存與載入

1. TVM 填第 1 項的輸入，名稱輸入「房貸A」→ 儲存情境
2. 清除表單，改填其他數字
3. 選「房貸A」→ 載入情境 → 欄位與方向（收到／付出）完全還原，結果需重新計算
4. 現金流工作表：存／載入後表格內容也還原
5. 重新整理頁面，情境仍在

## E. 匯出與匯入

1. 設定頁 → 匯出 JSON → 下載 `bacalc-backup-日期.json`，訊息顯示情境與紙帶筆數
2. 清除全部資料（確認對話框）→ 情境、紙帶、記憶清空
3. 匯入 JSON（合併）→ 資料回來；再選「取代」→ 先出現確認對話框
4. 匯入非 JSON／損壞檔 → 顯示錯誤、本機資料不變

## F. 設定重新顯示

1. 設定：小數位數改 4、千分位關閉、日期格式改 dd/mm/yyyy → 立即生效
2. 回 TVM 第 1 項：PMT 顯示 -1798.6516（無千分位）；日期欄位依新格式顯示
3. 重新整理 → 設定仍保留；改回預設

## G. Google Drive 同步（需使用者 Client ID）

> 需使用者提供自己的 OAuth Client ID（申請方式見 `docs/google-oauth-setup.md`），本表無法代測。

1. 未輸入 Client ID 時，連結鈕停用且不會連到 Google
2. 輸入 Client ID 並儲存 → 連結授權 → 上傳 → 顯示成功
3. 只改本機記憶 → 下載 → 應出現衝突／覆蓋確認，三個選項行為正確
4. 離線時連結／上傳／下載鈕停用並說明原因
5. 中斷連結後不再連到 Google
